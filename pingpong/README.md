# Jalilo Pong

A two-player table tennis game built with Flutter. Control each paddle by dragging it vertically on the court.

## Features

- Easy, medium, and hard difficulty levels that adjust ball speed.
- First player to reach five points wins.
- Start screen, live score, and replay controls.
- Responsive court for Android, web, and desktop.

## Run

Install Flutter, then run:

```sh
flutter pub get
flutter run
```

To run the widget tests:

```sh
flutter test
```

## Android

Enable USB debugging on your Android device, connect it to your computer, and select it with:

```sh
flutter devices
flutter run -d <device-id>
```
